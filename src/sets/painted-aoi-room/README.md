# プレビュー用のアオイの部屋

AnimeVRM 本体の `packages/content/src/sets/painted-aoi-room/` から部屋の描画実装を取り込み、こちらのプレビュー用に `layout.ts` の寸法・家具配置を調整している。壁・床の AVIF と家具・小物の GLB は `public/textures/painted-aoi-room/` に置く。

`src/main.ts` の場所は本体の `assets/studio/locations.json` の `aoi_house_frontlit` を基にする。床のプレビューの原点は `STANDING_ORIGIN` より 0.55 m 手前（+z）に取る。人物の正面側 `(0.8, 1.3, 2)` から照らし、影は茶系・濃さ 0.4・ぼかし 3、光条とレンズフレアは無効。カメラはモーションの体の範囲に合わせて自動で構図を決め、OrbitControls で回す。

座り・横座り・寝そべりと「座って上体をひねる」は `src/previewPlacement.ts` でベッド上に配置する。体の範囲の中心を `BED` の中央に合わせ、床基準のモーションをマットレスの高さ `BED.top`（0.5 m）だけ上げる。寝そべりは腰から頭への向きを枕側（-z）へ揃え、顔が立体の枕に埋まらないよう 0.2 m 足元側へずらす。カメラの注視点にも同じ移動・回転を適用し、座りは少し上、寝そべりはさらに高い斜め上から撮る。配置はプレビューだけに適用し、ダウンロードする FBX は元の座標のまま。

接地は `src/contactProfiles.json` と `src/fbx/contact.ts` で補正する。指定の寝姿5種は胴の軸と腰の高さ、座り系17種はお尻の高さを合わせる。腰を下げた分だけ膝・足・支える手を沈めることはせず、脚の長さを保つ IK と、膝・腿に置いた手の追従を使う。この骨の補正は呼吸を付ける前に適用し、保存する FBX にも含める。布団内のぬいぐるみに体が重ならないよう、対象の表示位置はベッド中央より 0.22 m 右へ寄せる。

補正量は配布モデル `aoi.vrm` の体・服の表面と、このベッドの布団の形状を測って調整した値。布団の配置と高さは FBX に含めず、モーションは床基準で渡す。

全身 P001・P002・P041・P042・P044・P046・P047・P048 は、説明文と指定された左右の支持点を `hands` に記録している。P041 は両掌を腿へ、P042 は両掌を膝の前のベッド面へ、P044 は両掌を後ろへ置く。P001・P002・P046・P047 は右掌をベッド面へ、P048 は右掌を右腿へ置く。女の子座り4種の足首と膝を `foldedLegs` で指定し、大腿・下腿の屈曲面を合わせる。支持する腕は肘の位置と前腕の軸回転を調整し、膝160°・肘155°・手首の曲げ85°/ねじれ40°をリグ用の検査範囲として使う。数値は人体共通の医学的上限ではない。

この8姿勢は枕やぬいぐるみに手が重ならないよう、`bedOffsetZ` でベッド中央より 0.5 m 足元側へ配置する。腿に手を置く姿勢は、前腕の太さを使う再生時の一律の押し出しを止め、FBX で合わせた手と腿の接触を保つ。他の姿勢へ切り替えたときは通常の手の押し出しへ戻す。`npm run check:contacts` は支持点・関節と呼吸0/80/150%のFBX読み戻しを検査する。

部屋は 4.2 m 四方、天井は 2.7 m。ベッドは幅 1.6 m × 長さ 2.6 m に広げ、マットレスの高さは 0.5 m のままにする。ナイトテーブルはベッドの横、机・椅子・本棚は拡張した右壁に合わせ、ローテーブル・ラグ・クッションもベッドに重ならないよう右側へ寄せる。体の大きさやモーションは変えず、寝そべりでもベッドの縁に手足が寄りすぎないようにする。

壁・床・天井は室内を向く片面なので、引きの構図でカメラが部屋を出ても手前の壁に遮られない。窓の空は透過し、既存の `SkyBackground` を見せる。家具はラグ以外が床に影を落とす。
